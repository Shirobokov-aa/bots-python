## 1. Маркировка интернет-рекламы

Статья: https://support.travelpayouts.com/hc/ru/articles/11261930210194

С 01.09.2022 (ФЗ о рекламе) для рекламы на RU-аудиторию:

1. Пометка **«Реклама»** + рекламодатель (или страница о нём)
2. Уникальный **erid** (токен ОРД) — в ссылке и/или на креативе
3. Отчёты в **ЕРИР**

### Что у TP считается рекламой

Ссылки, баннеры, **некоторые** виджеты — если проект с языком «Русский».

API / White Label / Targeted Offers / Travel App — **не** маркировать.

### Что делает Travelpayouts за партнёра

После формы «Закон о рекламе»:

- erid в партнёрских ссылках и виджетах
- пометка на виджетах в коде
- блок «инфо о рекламодателе» копируется в Tools → Ссылки
- отчёты в ЕРИР (если не отказались)

### Что делаем мы в Telegram

- Партнёрская ссылка из ЛК / Links API (erid уже внутри)
- **В каждом посте** со ссылками — текстовая пометка «Реклама» + рекламодатель  
  (для сайта достаточно блока на странице; для соцсетей — **каждый** пост)

WordPress / Chrome extension: erid **не** ставится автоматом — не использовать для продакшена канала.

### Штрафы за немаркировку (из статьи TP)

| Кто | Сумма |
|-----|-------|
| Физлицо | 10–30 тыс ₽ |
| ИП | 30–100 тыс ₽ |
| Юрлицо | 200–500 тыс ₽ |

### Отказ от авто-отчётности TP

Письмо на support@travelpayouts.com: ФИО/юрлицо, ИНН, URL, скрины регистрации в ЕРИР как рекламораспространитель + площадка. Дальше сами в ОРД. Пометка из ЛК пропадёт.

Срок давности: пост старше года без репоста/продвижения — обычно истёк; платный буст / репост = новое нарушение. При правке старого поста — обновить маркировку.

## 2. Ставка НДС для ЕРИР

Статья: https://support.travelpayouts.com/hc/ru/articles/31212920225170

Если страна = Россия и статус = **ИП или юрлицо** — поле «Ставка НДС» обязательно.

Зачем: ОРД требует ставку в актах; сбор 3% считается от суммы **без** НДС.

Где: Профиль → Закон о рекламе → Изменить данные → Ставка НДС → Сохранить.

Без ставки: акты/ЕРИР кривые, сбор может посчитаться неверно, ответственность на владельце реквизитов. Реформа 2026 — уточнять у бухгалтера.

## 3. Регистрация в Роскомнадзоре (10 000+)

Статья: https://support.travelpayouts.com/hc/ru/articles/28588710393618

С ноября 2024: ресурсы с аудиторией **от 10 000** подписчиков/охвата, размещающие рекламу (в т.ч. партнёрские ссылки/виджеты) — регистрация в реестре РКН.

Как: https://rkn.gov.ru → заявка в реестр владельцев рекламных систем (площадка, владелец, охват, характер рекламы).

Без регистрации: запрет сотрудничества рекламодателям, штрафы до 500 000 ₽, данные не в ЕРИР.

Пока канал <10k — не блокирует старт, но держать в уме.

## 4. Сбор 3% с интернет-рекламы

Статья: https://support.travelpayouts.com/hc/ru/articles/28845366678418

С 01.04.2025: сбор **3%** (не налог) с дохода от распространения интернет-рекламы.

- Админ: ЕРИР / РКН; TP **не** удерживает и **не** считает 3% сам
- Платит первый российский участник цепочки, получивший деньги
- Часто при иностранных бренде + TP юрлице сбор падает на **партнёра-гражданина РФ**
- Начисляется на сумму **акта** (подтверждённые брони / выплаты), не на каждый клик
- Квартал; уплата до 5-го числа 3-го месяца после квартала
- Гражданство РФ важно; налоговое резидентство другой страны — нет
- Личные (нерекламные) ссылки — не маркируются, сбор не про них

**Travelpayouts компенсирует** сумму сбора: скрин из ЛК ЕРИР с начислением → support → на баланс. Уплатить в ЕРИР всё равно самому.

Спор по начислению: erir.support@rkn.gov.ru

## 5. Запрет рекламы на заблокированных / нежелательных ресурсах

Статья: https://support.travelpayouts.com/hc/ru/articles/28588860075538

С **01.09.2025** нельзя размещать рекламу (в т.ч. инструменты TP) на ресурсах нежелательных организаций и с ограниченным доступом в РФ.

Примеры из статьи: Instagram, Facebook (Meta*), X (Twitter), Discord, Viber и др.

Для партнёров TP:

- Нельзя новые ссылки/виджеты/умные инструменты на запрещённых площадках
- Старое до 01.09.2025 удалять не обязательно (нет обратной силы), но **не** обновлять/репостить/закреплять
- Убрать TP из описаний профилей на запрещённых платформах
- TP перестаёт отчитываться по маркировке с таких ресурсов
- Нарушение оферты: блок аккаунта, стоп выплат, убытки бренда

**Telegram / VK / свой сайт / бот** — рабочие каналы для RU. Instagram/FB/X для партнёрок TP на RU-аудиторию — нет.

## 6. Обновление erid в инструментах

Статья: https://support.travelpayouts.com/hc/ru/articles/34098628515730

Когда TP или бренд меняет юрлицо — новые erid. ЛК уже отдаёт свежие ссылки; старый контент надо обновить.

Способы:

1. **Drive** на сайте — авто-обновление erid (только если erid уже был в URL) + блок рекламодателей; якорь: `<div class="tp-advertiser-info"></div>`
2. Вручную: Tools → новая ссылка → заменить
3. Telegram: новые посты только со свежими URL; старые популярные — править по возможности

Список брендов с переподписанным договором (Travelspark Limited) — в [programs.md](programs.md). Для нас критично: **Островок, Отелло, Яндекс Путешествия**.
