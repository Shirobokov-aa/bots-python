## Зачем

Первый контакт без подписчиков: кто мы, как пользоваться, без крика «горящее!!!».

## Описание канала (About)

Скопировать в Telegram → Управление → Описание:

```
Билет на стол — спокойные подборки авиа с ценами.
Отели: ссылки на поиск у партнёров (цены на их сайте).

Бот: [ссылка на бота]
Не витрина «купи сейчас» — инфо для поездки.
Реклама по партнёрским ссылкам Travelpayouts.
```

Подставить реальную ссылку на бота.

## Закреплённый пост

```
Билет на стол

Здесь — маршруты с реальной ценой билета (Aviasales)
и кнопки поиска отелей на те же даты.

Как пользоваться
1. Смотри пост: город, цена, даты
2. «Смотреть билеты» — открыть варианты
3. Кнопки отелей — Островок / Яндекс Путешествия

Бот в ЛС: [ссылка]
Команды: /flight · /hotel · /tour · /alert

Цены отелей в канале пока нет (API закрыт) —
цифру смотри у партнёра по кнопке.
```
