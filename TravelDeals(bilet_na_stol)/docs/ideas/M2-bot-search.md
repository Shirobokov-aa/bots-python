## Зачем

Юзер сам задаёт маршрут → получает варианты со ссылками. Удобнее, чем только смотреть чужие подборки. Канал = трафик, бот = конверсия «хочу именно туда».

## Как выглядит для юзера

В боте:

> /flight  
> Откуда? Москва  
> Куда? Анталья  
> Гибкие даты? да  

Ответ: 2–3 варианта цена + пересадки + кнопка Aviasales.  
Из канала: «Искать свой маршрут → @бот» (позже deep-link P7).

## Критерий «готово»

Новый юзер из канала за 1 минуту находит маршрут и открывает партнёрскую ссылку; без token бот честно говорит, что поиск временно недоступен.
