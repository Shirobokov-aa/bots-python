# API-CLOUD.ru — каталог для ботов

Снимок методов и цен [api-cloud.ru](https://api-cloud.ru/) для продуктов в `bots-python/`.

**Не** код интеграции. Только справочник. Источник цен: [тарифы](https://api-cloud.ru/tarif).

| Файл | Зачем |
|------|--------|
| [`CATALOG.md`](CATALOG.md) | Человекочитаемый каталог API → методы → цена |
| [`catalog.json`](catalog.json) | Машиночитаемый (мультибот / расчёт COGS) |
| [`scenarios.md`](scenarios.md) | Черновик сценариев мультибота |

## Правила биллинга (на дату снимка)

- Платишь только за ответ `"status": 200`.
- Не оферта. Токен выдают вручную (заявка → support@api-cloud.ru).
- Мин. платёж (аккаунты после 29.02.2024): **700₽/мес**, если &lt;2000 запросов/мес; иначе только per-request.
- Timeout клиента ≥ **120с**.
- Токен: query `token=` или header `Token: …`.

## Как обновлять

1. Снять актуальные цены с https://api-cloud.ru/tarif  
2. Обновить `CATALOG.md` + `catalog.json`  
3. Строка в Changelog ниже + дата `sourced_at` в JSON
