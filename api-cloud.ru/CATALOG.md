# Каталог API-CLOUD — методы и цены

Снято: **2026-09-28** с [тарифов](https://api-cloud.ru/tarif) + страниц документации.  
Цены в **₽ за успешный запрос** (`status: 200`).  
`price: null` / `?` = на странице тарифов метод есть в описании, но цена в таблице не указана явно — смотреть `inquiry.price` в ответе.

Базовый паттерн: `GET https://api-cloud.ru/api/<endpoint>?type=<method>&…&token=…`

---

## Общие условия

| Условие | Значение |
|---------|----------|
| Мин. платёж (&lt;2000 req/мес, после 29.02.2024) | 700 ₽/мес + запросы |
| ≥2000 req/мес | только запросы |
| Пополнение ЮЛ/ИП | от 1000 ₽ (первый счёт ≥3000 ₽) |
| Пополнение ФЛ (UnitPay) | от 2000 ₽ |
