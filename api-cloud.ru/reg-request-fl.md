# Заявка на регистрацию (ФЛ) — api-cloud.ru

Источник: экран «Инструкция по регистрации физического лица» на api-cloud.ru.  
Кому: **support@api-cloud.ru**  
Ответ: до ~7 рабочих дней. Анонимные ящики не принимают. В чате заявки не принимают.

## Тема письма

```
Регистрация физ лицо. Срочность: средняя
```

(срочность поменяй: низкая / средняя / срочная / очень срочная)

## Тело письма (готово к отправке)

```
Здравствуйте.

Прошу зарегистрировать меня как физическое лицо для доступа к API.

1) Необходимые API и планируемый объём запросов в месяц

Этап 1 продукта — сервисы для автовладельца (Telegram-бот): проверка штрафов, история ТС, страхование, сопутствующие проверки по авто.

API (по названиям с вашего сайта):
• API ГИБДД (штрафы, ограничения, розыск, ДТП, ВУ, ЕАИСТО через ГИБДД)
• API ЕАИСТО (пробег / ДК, при необходимости)
• API РСА (НСИС) — КБМ, ОСАГО
• API ФНП: Реестр залогов (+ лизинг / Федресурс по ТС)
• API Отзывные кампании (Росстандарт)
• API Фотографии ТС / Номерограм
• API Конвертер VIN ↔ рег.номер
• API Оценка стоимости авто
• API ФТС (таможня легковых)
• API Электронный ПТС
• API ФГИС «Такси» и/или проверка ТС по базе такси
• API Автодор: платные дороги
• API Московский транспорт (пропуск / РНИС) — опционально, этап 1.1
• API ФРИ — опционально

Планируемый объём на старте (MVP / тесты + первые пользователи):
примерно 1 500–3 000 успешных запросов в месяц.
При росте готов увеличить лимит и сообщить отдельно.

2) Цели использования выбранных API

Разработка и эксплуатация Telegram-бота для автовладельцев и покупателей б/у авто:
— проверка неоплаченных штрафов ГИБДД;
— отчёт по VIN / госномеру (ограничения, розыск, ДТП, залоги, ОСАГО, ЭПТС и др. по открытым данным);
— вспомогательные проверки (КБМ/ОСАГО, долги на платных дорогах).

Данные показываем пользователю по его запросу. Не используем API для массового сбора чужих баз, спама или обхода ограничений источников.

3) Форма регистрации: физическое лицо

Прошу выдать регистрационный код / инструкции для создания личного кабинета и демо-доступ (если доступен), чтобы протестировать методы до полноценной нагрузки.

Готов ознакомиться с тарифами и договором/офертой для ФЛ и оплатить счёт.
```
