**Document version:** v3.3  
**Last updated:** 2026-09-24  
**Статус идеи:** сырая. Базовые решения зафиксированы; ниши ещё не разобраны.

Живой документ мышления. Правки копим сюда, не в чате.  
Маркетинг-контекст: `.agents/product-marketing.md`.

---

## 1. Одна фраза (суть)

Построить **портфель** TG-продуктов (боты / каналы / чаты), которые можно **масштабировать** и на которых можно **зарабатывать**. Ниши могут быть **абсолютно разными** — сходство тематики не требуется.

«Один раз настроил → крутится в фоне» — это **общий контур** хорошего автомата (мало ручных рук на единицу выручки), а не единственный смысл системы и не обязательный клон SmartDigest.

## 2. Путь работ (зафиксировано)

1. В `ideals.md` уже банк идей → **придумать/выбрать** под реализацию (не обязательно «пара похожих»).  
2. **Сначала анализ идей** (ещё не делаем) — фильтр: масштаб + деньги + риск.  
3. Потом **полностью реализовать** выбранные.  

Сейчас: только мышление и фиксация смысла. Анализ ideals — отдельно, по команде.

## 3. Первый продукт — смысл бота (SmartDigest)

Раньше в VISION мелькало слово «ядро» — это путало. Простыми словами:

**Что делает бот:**
1. Кидаешь в бота ссылки / @юзернеймы **открытых** Telegram-каналов (список источников).  
2. Бот фоном читает новые посты из этих каналов.  
3. ИИ сжимает важное в **одну красивую выжимку**.  
4. Отдаёт **одно сообщение-выжимку в бот**. Куда постить дальше (канал и т.п.) — решим позже.

Не «абстрактное ядро платформы». Это **один** конкретный продукт в портфеле: **дайджест из чужих открытых каналов → одно сообщение**.

RSS/сайты в текущем коде SmartDigest — побочный задел; главный UX-смысл сейчас = TG-каналы → одна выжимка.

Остальная «OS» (дашборд, много ниш, CPA, clone) — обёртка вокруг автоматов портфеля, не вместо них.

---

## 4. Масштаб системы (зачем больше одного продукта)

Один бот ≠ вся система. Цель — **несколько** работающих линий выручки.

Продукты **не обязаны** повторять паттерн «источники → выжимка». Могут быть: утилита в боте, коммьюнити-чат + бот, CPA-алерты, квизы, модерация для админов — что угодно, если:

1. **Масштаб** — рост аудитории/инстансов без линейного роста рук  
2. **Деньги** — понятный путь (реклама / CPA / VIP / B2B админам / комиссия)  
3. **Риск ок** — без серости, которая жжёт аккаунты и доверие  

«Собрал → сжал → опубликовал» — удобный шаблон для части идей (#8 и родственники), не фильтр для банка идей.

Слои (для разработки, не для маркетинга; не каждый продукт использует все):

| Слой | Делает |
|------|--------|
| Сбор / вход | Источники, юзер-запросы, события чата |
| ИИ (если нужен) | Выжимка, ответы, генерация |
| Публикация / UX | Пост, сообщение в боте, кнопки в чате |
| Рост | Как люди сами приходят |
| Деньги | CPA / реклама / VIP / B2B |
| Дашборд | Next.js: видно что живо (позже) |

Стек: **FastAPI + PostgreSQL + Next.js + Telegram**.

## 5. Контур «мало рук» (не догма)

> Хороший автомат: выключил ноут — ценность всё ещё капает (контент / алерты / сервис в чате). Заходишь проверить и крутить рост/деньги, не писать руками каждый пост.

Это **желаемый контур**, не закон. Если продукт масштабируется и кормит — ок, даже если иногда есть ручной слой (модерация, редкий кураторский пост, разовые ивенты).
