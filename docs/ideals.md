### Детали волны 3 (сырой текст)

**#46 Seller Assistant**  
Продавец подключает API-ключ. Бот шлёт сводку: остатки, выпадение из топ-10 по запросу, конкурент −5% цены, неотвеченные отзывы. Селлеры платят за экономию ручной аналитики.

Разбор API (2026-09-28): основной контур = **WB Seller API** + **Ozon Seller API** (не Performance). Performance = только реклама, отдельный OAuth.  
Матрица фич → API:

| Фича в идее | WB | Ozon | Блокер |
|-------------|----|------|--------|
| Остатки | Analytics stocks / warehouses | `/v4/product/info/stocks`, FBS warehouse | нет |
| Позиция в поиске (свои SKU) | `/api/v2/search-report/*` | нет прямого аналога в Seller | WB: нужен **Jam**; Ozon: гэп |
| Цена конкурента | нет в Seller API | Pricing Strategy `/competitors`, `/product/info` | WB: только публичный каталог/парсинг или ручной nmId; Ozon: через стратегии |
| Неотвеченные отзывы | Communications `feedbacks` (`isAnswered=false`) | `/v1/review/list` `UNPROCESSED` | Ozon: часто **Premium Plus** |
| Реклама (опц.) | отдельный Promotion/Ads | **Performance API** (отдельные client_id/secret) | 2-й ключ |

MVP без серости: остатки + отзывы (+ опц. утренняя сводка). Поиск/конкуренты — фаза 2.

**#47 Пакетные туры** → лок как TravelDeals **P3** (`TravelDeals/docs/ideas/P3-hot-packages.md`).  
Не «только авиа», а готовый пакет; фильтры горящих; после MVP.
