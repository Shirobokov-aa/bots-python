## 1. Разбор запроса → STATUS.md

1. Разбить запрос на конкретные задачи.
2. До работы записать/обновить STATUS нужной линии:
   - Кросс-система / VISION / бизнес → `bots-python/STATUS.md`
   - Конкретный бот в `bots-python/` → `<имя бота>/STATUS.md` (если файла нет — создать по шаблону)
3. Секции: **В работе** / **Очередь** / **Сделано** (`### YYYY-MM-DD` + 1–2 предложения).
4. По завершении — перенести задачу в «Сделано».

В STATUS рядом с задачей сразу писать предложенный коммит:
`- [ ] … → commit: feat(scope): …`

Канон: `docs/VISION.md`. План: `docs/business-plan.md`. Согласовано: `docs/agreed.md`.  
Маркетинг: `docs/product-marketing.md`.

## 2. Коммиты — только предложение

- На каждую задачу предложить Conventional Commit: `тип(область): кратко`.
- Типы: `feat` | `fix` | `docs` | `refactor` | `chore` | `test` | `style` | `perf`.
- **Не коммитить**, пока пользователь явно не попросит.

## 3. Monorepo

Один git на `bots-python/`. Боты = папки-сервисы. Секреты только в `<Bot>/.env`.

## STATUS — шаблон

```markdown
# <BotName> — статус

## В работе
- [ ] краткое название → commit: `feat(scope): …`

## Очередь
- [ ] …

## Сделано
### 2026-09-11
- **Заголовок.** Что сделали и итог. → commit: `fix(scope): …`
```
