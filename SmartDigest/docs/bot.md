# Бот в Telegram

Пользователь присылает RSS, сайт или публичный `@канал`. Бот кладёт ленту в источники и раз в день (или по кнопке) присылает выжимку.

## Команды

| | |
|---|---|
| `/start` | кратко как работает |
| `/help` | список команд |
| `/sources` | ленты + пауза / обновить / удалить |
| `/digest` | выжимка за последние 24 часа |
| `/time` | час ежедневной рассылки |
| `/vip` | лимиты |
| `/cancel` | сброс FSM |
| `/grant_vip <telegram_id>` | только `ADMIN_TELEGRAM_IDS` |

Клавиатура: «Источники», «Дайджест», «Время», «Помощь», «VIP».

## Что можно добавить

- RSS/Atom URL
- сайт — бот ищет `<link rel="alternate">` и типовые `/rss`, `/feed`
- публичный канал `@name` / `t.me/name` через страницу `t.me/s/name`

Приватные каналы и инвайты (`t.me/+…`) не поддерживаются.

## Дайджест без ИИ

- окно 24 часа (`DIGEST_WINDOW_HOURS`)
- повтор: одинаковый нормализованный заголовок, URL без utm или `content_hash`
- реклама: маркеры вроде `erid`, «промокод», «на правах рекламы»
- длинное сообщение режется на части < 3500 символов
