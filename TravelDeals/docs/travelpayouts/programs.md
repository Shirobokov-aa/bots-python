## Зачем программы боту

1. Подписка проекта на бренд → Links API / кнопки дают CPA.
2. Без подписки Links API вернёт ошибку «Нет подписки на бренд».
3. Для RU-контента после формы «Закон о рекламе» в ссылки вшивается **erid**.

## Чеклист в ЛК (сделать руками)

### TRS / .env
- [ ] В Tools URL есть `?source=578817` → это `TRAVELPAYOUTS_TRS`
- [ ] В `.env` заданы: `TRAVELPAYOUTS_TOKEN`, `TRAVELPAYOUTS_MARKER`, `TRAVELPAYOUTS_TRS=578817`
- [ ] Без TRS кнопки отелей открывают прямые URL (CPA может не трекаться)

### Программы
- [ ] Открыть каталог → подписать нужные P0/P1 на проект `578817`
- [ ] P0 минимум: Aviasales, Яндекс Путешествия, Островок
- [ ] Tools → Ссылки: тест Островок + Яндекс + Aviasales → есть erid после формы закона
- [ ] Записать в этот файл фактический список «Мои программы»
- [ ] Проверить комиссию / cookie / гео по каждой программе (карточка бренда в каталоге)

### Быстрый тест клика
1. Бот `/hotel` → Анталья → 7 ночей → открыть Островок и Яндекс.
2. В статистике TP (через сутки) или в «Ссылках» — клик виден.
3. Канал `/post_now` → кнопки отеля на даты **вылета**, не «+21 день».
