# API по отелям (цены)

Раздел HC: https://support.travelpayouts.com/hc/ru/sections/200989127  
Дата снятия: 2026-09-28.

## Вердикт

**Hotellook / старый hotel price API в разделе нет.**  
Цены выводить можно — через **Яндекс Путешествия** или **Суточно.ру**, но не «из коробки»: заявка + пороги трафика.

Сейчас в боте (P8): deeplink Островок / Яндекс (+ Links API) — **без списка цен**. Это осознанный fallback.

---

## 1. Яндекс Путешествия — главный кандидат на цену

Статья: https://support.travelpayouts.com/hc/ru/articles/19677424987026

### Что даёт

Методы раздела «Запрос данных по отелям» (кроме `GET hotels/hotel/reviews`):

| Метод | Описание |
|-------|----------|
| `GET hotels/suggest` | Регионы и отели по поисковой строке |
| `GET hotels/selection` | Сниппеты отелей (ознакомительно) |
| `GET hotels/search` | Сниппеты **с доступными предложениями** под параметры поиска |
| `GET hotels/hotel` | Карточка отеля по id |
| `GET hotels/hotel/images` | Фото |
| `GET hotels/hotel/offers` | **Номера и цены** по id отеля + параметры поиска |
| `GET hotels/top-offers` | Лучшие предложения по id отелей |
| `GET feeds/hotels/temporary_url` | Ссылка на gz-фид статичного списка отелей |

Именно `search` / `hotel/offers` / `top-offers` = путь к цене в боте/канале.

### Доступ

1. Проект в ЛК TP со ссылкой на ресурс (Telegram-канал/бот ок, если принимают).
2. Письмо на **support@travelpayouts.com** — запрос API Яндекс Путешествий.
3. **Обязательно** указать почту на домене **`@yandex`**.
4. После подтверждения — OAuth:  
   `https://oauth.yandex.ru/authorize?response_type=token&client_id=b0ca9cd48f66420c9995c0776f2243a8`
5. Заголовок: `Authorization: OAuth <token>`
6. Токен живёт **1 год** → потом снова support.

### Порог

Контентные проекты от **~5 000 MAU**, тематика travel / отели / авиа / жд.  
Бренд готов смотреть отклонения от критериев.

### CPA

Все URL из API **обязательно** завернуть в партнёрские (Links API / Инструменты → Ссылки).  
Проект должен быть **подключён к программе** Яндекс Путешествия.

Для нас: deeplink Яндекса уже строим в `hotel_links.py` → тот же URL кормить в Links API с `trs=578817`.

## 2. Суточно.ру

Статья: https://support.travelpayouts.com/hc/ru/articles/4407224907282

### Что даёт

- Предложения по объектам **с ценами**
- Предложения по самым дешёвым номерам в отеле
- Отдельно фид: https://support.travelpayouts.com/hc/ru/articles/360028511592

Base URL: `https://api.sutochno.ru`

### Доступ

Заявка в support Travelpayouts:

- URL сайта / ресурса
- описание проекта
- MAU
- телефон + ФИО владельца
- какие данные нужны из API

Срок рассмотрения: в среднем **до 3 недель**.

Ниша: посуточная аренда РФ (+ зарубежье) — не полный заменитель «отель на курорте», но цены есть.

## 3. Чего нет

- Hotellook partner API — убран из секции «API по отелям».
- Публичного «бесплатного hotel price API без заявки» в TP сейчас нет.
- Островок / Отелло в этом разделе **как price API не фигурируют** — только как партнёрские программы (ссылки), см. [programs.md](programs.md).

## 4. План для «Билет на стол»

| Этап | Действие | Цены? |
|------|----------|-------|
| Сейчас (P8) | Deeplink + Links API | Нет |
| Рост аудитории | До ~5k MAU канала/бота | — |
| Заявка Яндекс | Черновик + ответ чата: [yandex-api-request.md](yandex-api-request.md) · whitelist + OAuth | Да после токена |
| Альтернатива | Заявка Суточно | Да (посутка) |
| До одобрения | Не обещать цену в `/hotel` | — |

Не путать:

- **программа в каталоге** → клик → CPA  
- **hotel price API** → цифры в сообщении  

Оба нужны для поста «отель от N ₽ + кнопка».
